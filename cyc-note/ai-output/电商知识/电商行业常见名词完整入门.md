## 业务流程总览

电商里的这些词，可以沿着一条业务流程来理解：

**决定卖什么 → 从哪里拿货 → 商品上架 → 吸引顾客 → 促成下单 → 发货售后 → 算清利润。**

其中，**选品是决定卖什么，铺货是批量把商品上架销售**。它们分别属于“商品决策”和“商品经营”环节，并不是二选一。

下面按这条流程，把常见名词讲清楚。不同平台的叫法和统计口径可能略有差异。

## 一、卖什么：选品与商品定位

| 名词 | 通俗解释 | 例子 |
|---|---|---|
| 选品 | 判断哪些商品值得卖，综合考虑需求、竞争、成本、利润和供应能力 | 比较保温杯、收纳盒、手机壳，决定先卖收纳盒 |
| 类目 | 平台对商品的分类 | 家居日用 → 收纳整理 → 桌面收纳 |
| 赛道 | 商家对某一市场方向的统称，比类目更灵活 | 宠物用品、户外露营、银发消费 |
| 细分市场 | 面向更具体的人群或场景 | 小户型厨房收纳、大学生宿舍收纳 |
| 刚需品 | 用户经常需要、较难长期不买的商品 | 纸巾、清洁用品 |
| 季节品 | 需求明显随季节变化的商品 | 凉席、暖手宝 |
| 标品 | 参数比较统一，容易直接比价的商品 | 同型号手机、同规格品牌电池 |
| 非标品 | 款式、设计、体验差异较大，难以仅按参数比价的商品 | 女装、装饰画 |
| 差异化 | 给用户一个选择你的理由 | 尺寸更适配、材质不同、组合更实用 |
| 同质化 | 商品和展示方式都很相似，竞争容易集中到价格上 | 多家店使用同一货源、同一组图片 |
| 蓝海 / 红海 | 商家对竞争状况的形容：相对不拥挤 / 竞争激烈 | 这是相对判断，不代表蓝海一定有需求 |
| 测品 | 先用小规模上架、推广或销售，验证商品有没有机会 | 先测试三款，看点击、成交、退款和利润 |
| 爆品 | 在一定时间内销量明显突出的商品 | 店里持续大量出单的一款收纳箱 |

选品不是单纯“找热门商品”。**有人买、你能卖得动、卖完能赚钱、货能持续供应**，才构成比较完整的判断。

## 二、怎么组织商品：铺货、精品和商品角色

| 名词 | 通俗解释 |
|---|---|
| 铺货 | 上架较多商品，通过覆盖更多需求和搜索词获取订单 |
| 精细化铺货 | 在铺货基础上筛选商品，优化标题、图片、价格，并淘汰表现差的商品 |
| 精品运营 | 聚焦较少的商品，对产品、内容、推广和服务投入更多精力 |
| 店群 | 同时经营多家店铺；它描述店铺数量和组织方式，不等于铺货 |
| 动销 | 商品产生实际销售；动销率一般衡量一定时期内有销量商品占商品总量的比例 |
| 滞销 | 商品长期卖不动，可能占用库存和资金 |
| 引流款 | 用来吸引顾客进入店铺的商品，利润可能较低 |
| 利润款 | 承担主要利润贡献的商品 |
| 形象款 | 用来展示品质、设计或品牌定位的商品 |
| 主推款 | 当前集中资源推广的商品 |

例如，一家收纳店上架 300 款商品寻找机会，属于铺货思路；只经营 10 款，并深入做设计、拍摄和推广，更接近精品思路。

**商品多不等于销量好，商品少也不等于精品。核心区别是资源怎么分配、运营做到多深。**

## 三、从哪里拿货：货源与供应链

| 名词 | 通俗解释 | 容易混淆的地方 |
|---|---|---|
| 货源 | 商品的供应来源 | 可以是工厂、品牌方、批发商等 |
| 供应链 | 从生产、采购到仓储、配送的一整套协作体系 | 不只是“找到一家便宜工厂” |
| 拿货价 / 采购价 | 采购商品时支付的价格 | 是否含税、含运费，需要明确 |
| 起订量（MOQ） | 供应商接受订单的最低数量 | 某款产品至少订 100 件 |
| 现货 | 已经有库存，可以安排发货 | 具体时效仍要看供应商 |
| 预售 | 先接受订单，再按约定时间交付 | 不代表随时有货 |
| 备货 / 囤货 | 提前采购并持有库存 | 发货可控，但有库存和资金压力 |
| 一件代发 | 收到订单后，由供应商直接向顾客发货 | 卖家仍需处理商品信息、订单和售后 |
| 无货源 | 通常指不预先持有库存，出单后再向其他来源采购 | 不等于没有供应商，也不等于零成本 |
| 分销 | 通过授权或合作关系销售上游商品 | 可以自己发货，也可以由上游代发 |
| 贴牌（常称 OEM） | 委托生产并使用自己的品牌，具体分工看合同 | 仅换包装不代表产品具有独特性 |
| ODM | 供应商提供设计和生产能力，品牌方选用或调整方案 | 与 OEM 的实际边界可能有交叉 |
| 账期 | 约定多久以后付款 | 先收货，30 天后向供应商付款 |

这里有三个不同维度：

- **铺货 / 精品**：怎么经营商品。
- **备货 / 代发**：库存和发货怎么安排。
- **自有品牌 / 分销**：以什么商品或品牌关系经营。

所以，一家店完全可以同时是“精品运营＋一件代发”。

## 四、怎么把商品放进店里：上架与商品信息

| 名词 | 通俗解释 |
|---|---|
| 上架 / 下架 | 让商品开始销售 / 停止销售 |
| 商品链接 | 一个商品的销售页面；商家说“做一个链接”，通常就是建立商品页面 |
| SPU | 将同一类商品的不同规格归在一起的商品单位，具体定义因系统而异 |
| SKU | 可单独管理价格、库存和订单的具体商品规格 |
| 标题 | 商品名称和描述词，帮助用户理解，也影响搜索匹配 |
| 主图 | 商品展示时最先被看到的图片，主要影响理解和点击 |
| 详情页 | 更完整地介绍尺寸、材质、功能、使用场景等信息 |
| 属性 | 平台要求填写的结构化信息，如品牌、材质、容量 |
| 关键词 | 用户可能用来搜索商品的词 |
| 长尾词 | 更具体、搜索意图通常更明确的关键词 |
| 卖点 | 商品对用户有价值、值得购买的特点 |

**SKU 举例：**同一款 T 恤有黑、白两种颜色，每种颜色有 S、M、L 三个尺码，通常对应 **6 个 SKU**。

“收纳盒”是比较宽泛的关键词；“宿舍桌面抽屉式收纳盒”是更具体的长尾词。

## 五、顾客怎么来：流量与推广

| 名词 | 通俗解释 |
|---|---|
| 流量 | 进入店铺、商品页、直播间等位置的访问 |
| 曝光 / 展现 | 商品或内容被展示的次数，不代表用户已经点进去 |
| 点击 | 用户点击商品或内容 |
| 自然流量 | 通过搜索、推荐等获得、未直接按广告购买的流量，但运营仍有成本 |
| 付费流量 | 通过广告投放获得的流量 |
| 搜索流量 | 用户主动搜索关键词带来的访问 |
| 推荐流量 | 平台根据用户兴趣等因素推荐带来的访问 |
| 公域 | 平台上的公共流量场景，如搜索页、推荐页 |
| 私域 | 商家能够持续触达用户的渠道，如会员体系、社群 |
| 种草 | 通过内容让用户产生兴趣或购买意愿 |
| 达人带货 | 通过内容创作者或主播推广商品 |
| 佣金 | 按约定向推广者、平台等支付的费用，可能按成交额比例计算 |
| 投流 | 为内容、直播间或商品购买广告流量 |
| 人群定向 | 在广告中设置希望触达的用户范围 |
| 重定向 | 再次触达曾浏览、互动等符合条件的用户 |
| 承接 | 用户来了以后，商品页、价格、客服等能否接住需求并促成购买 |

商家常说的“**人、货、场**”，就是：卖给谁、卖什么、在什么场景里卖。

“**人找货**”常指用户先有需求再搜索；“**货找人**”常指通过推荐、短视频或直播，让用户发现商品。

## 六、来了多少人、买了多少：核心数据

| 指标 | 通俗解释 | 常见计算方式 |
|---|---|---|
| PV | 页面被浏览的总次数 | 同一个人看多次，可能累计多次 |
| UV | 去重后的访客数 | 统计方式取决于平台 |
| 点击率（CTR） | 看到的人或次数中，有多少产生点击 | 点击量 ÷ 展现量 |
| 转化率（CVR） | 访问或点击后，完成指定行为的比例 | 如支付买家数 ÷ 访客数 |
| 加购率 | 访问后把商品加入购物车的比例 | 分母和是否去重需看平台 |
| 客单价 | 平均每位成交顾客花多少钱 | 成交金额 ÷ 成交买家数 |
| 件单价 | 平均每件商品卖多少钱 | 成交金额 ÷ 成交件数 |
| GMV | 一定时期内的商品交易总额 | 是否含未支付、退款订单，需看口径 |
| CPC | 每次广告点击的平均成本 | 广告花费 ÷ 点击量 |
| CPM | 每千次广告展示的成本 | 广告花费 ÷ 展现量 × 1,000 |
| CPA | 每次目标行为的平均成本 | 广告花费 ÷ 目标行为次数 |
| 复购率 | 买过的用户中，再次购买的比例 | 必须同时明确统计周期和用户范围 |

**GMV 不是利润，也不一定等于最终到账收入。**

另外，“ROI”在电商交流中经常被用来指“成交金额 ÷ 广告花费”，也叫投产比；严格说，这更接近广告支出回报率（ROAS）。看到“投产比 3”，应先确认分子是支付成交额、扣退款后的成交额，还是其他数值。

## 七、怎么买得更多：促销与成交

| 名词 | 通俗解释 |
|---|---|
| 转化 | 用户完成目标行为，如下单、支付；需要明确是哪一步 |
| 促单 | 通过答疑、优惠、服务说明等帮助用户做出购买决定 |
| 满减 | 达到指定金额后减免一部分价格 |
| 优惠券 | 满足条件时可抵扣的优惠凭证 |
| 连带销售 | 用户买一种商品时，同时购买相关商品 |
| 组合装 / 套装 | 将多个商品一起销售 |
| 加价购 | 满足条件后，加一定金额购买另一件商品 |
| 关联推荐 | 在页面中推荐相关商品 |
| 复购 | 顾客购买后再次购买 |
| 用户生命周期价值（LTV） | 用户在一段关系周期内带来的累计价值，可能按收入或贡献利润衡量 |

例如，买收纳盒时推荐标签贴，是关联推荐；顾客一起买了标签贴，形成连带销售。

## 八、下单以后：仓储、履约与售后

| 名词 | 通俗解释 |
|---|---|
| 履约 | 按订单约定完成配货、包装、发货和交付等工作 |
| 云仓 / 第三方仓 | 由外部服务商提供仓储和订单发货服务 |
| 打单 | 打印快递面单或其他订单作业单据 |
| 揽收 | 快递公司实际接收包裹 |
| 发货时效 | 从约定起点到完成发货的时间，具体以平台定义为准 |
| 缺货 / 断货 | 商品没有足够库存可售或无法及时交付 |
| 库存周转 | 库存转化为销售的速度 |
| 安全库存 | 为应对需求波动或补货延迟预留的库存 |
| 退货退款 | 顾客退回商品后退款 |
| 仅退款 | 无需退回商品即可退款，适用条件由具体交易和平台规则决定 |
| 逆向物流 | 商品从顾客返回商家或仓库的物流过程 |
| 退款率 / 退货率 | 退款或退货在相关订单中的比例，两者不是同一指标 |

实际经营时，不能只看“卖出去多少”，还要看“最后留下多少成交、退款产生了多少成本”。

## 九、最终有没有赚钱：成本与利润

| 名词 | 通俗解释 |
|---|---|
| 营业收入 | 按相应会计口径确认的销售收入，与 GMV 不完全相同 |
| 毛利 | 收入扣除对应销售成本后的差额 |
| 毛利率 | 毛利占收入的比例 |
| 贡献利润 | 收入扣除特定范围内的变动成本后，剩余用于覆盖固定费用和形成利润的金额 |
| 净利润 | 进一步扣除经营费用、税费等后的利润 |
| 平台扣点 | 平台按交易金额等收取的费用 |
| 获客成本（CAC） | 平均获得一个新客户花了多少钱 |
| 盈亏平衡 | 收入刚好覆盖对应成本费用 |
| 现金流 | 资金实际流入和流出的情况 |
| 回款周期 | 从投入或成交，到收到可用资金所需的时间 |

### 利润计算示例

一件商品卖 100 元，假设没有退款，暂不考虑税费：

| 项目 | 金额 |
|---|---:|
| 销售收入 | 100 元 |
| 商品成本 | −35 元 |
| 包装和发货运费 | −8 元 |
| 平台费用 | −5 元 |
| 广告费用 | −25 元 |
| 剩余 | **27 元** |

这 27 元还要承担人工、房租、软件等费用，**不能直接叫净利润**。

如果广告花费 25 元带来 100 元成交，投产比是 **4**。但这个数值本身不能证明盈利：采购成本、退款、运费和其他费用都会改变结果。

还有两个经常混淆的概念：进价 50 元、售价 100 元，在仅计采购成本的简化情况下，毛利率是 **50%**；相对进价的加价率则是 **100%**。

## 十、把行业术语翻译成日常表达

你以后听到一句话：

> “先铺货测品，找到动销款，再优化主图和详情页，投流放量，同时盯住投产和退款率。”

它的意思就是：

**先上架一批商品观察哪些有人买，再改善表现较好商品的展示，用广告尝试扩大销量，并持续检查广告效率和退款情况，判断扩大销售后是否还能赚钱。**
