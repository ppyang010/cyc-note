## tool基类
只有
名称,描述,参数json格式,执行方法,。`schema()` 把前三样拼成 OpenAI function calling 要的格式，
一个工具只有上面这些

发给模型，模型据此决定要不要调、怎么填参数。
没有派生工具
都是从tool 下的直接子类

### edit_file
使用 old_string/new_string
使用旧字符串替换新字符串的方式,并且要求旧字符串只出现一次
0次->没找到  返回文件开头 帮助让模型重新对照
对于一次> 拒绝仔细, 提示 出现了N次,请多带上下文使其唯一  ---  报错教模型怎么修改请求

diff 反向使用  配套 diff ,工具侧生成diff 让模型检查( 让模型生成diff不可靠)
TF-8 预检：编辑前先 read_text(encoding="utf-8")，失败返回人话而非解码异常栈。给模型的每条错误都该是「人话」，这是贯穿所有工具的隐性准则。

让cd在多次命令之间可以记住

subprocess.run 每次起独立进程，cd 只是那个瞬时进程的私有状态，进程一死就没了。所以模型执行 cd /tmp/project 后再 ls，ls 会在原始目录跑。模型会理所当然地困惑：“我明明 cd 过了。”
