创建skill时需要的规则

如果有凭证,个性化参数等配置遵循下面的规则
1.配置信息存放到用户目录的 .ai-skill-config 目录下
2.使用时检查凭证信息,如果没对应的配置询问用户获取,并保存

-----------

```

[需求]

在开始之前，请先按下面流程协作：

1. 先用你自己的话复述：

- 你理解的问题是什么

- 真正目标可能是什么

- 预期交付物是什么

- 你当前倾向采用的实现思路是什么

2. 明确列出你不确定的地方，以及你正在做的关键假设。

3. 如果存在会明显影响方案、实现范围、风险或最终结果的关键不确定性，先向我提问。

要求：

- 每轮最多 3 个问题

- 用编号列出，方便我逐条回答

- 优先问最影响决策的问题，不要把可以自行合理假设的小问题都抛给我

4. 在我明确说“可以开始”之前：

- 不要写代码

- 不要修改文件

- 不要执行会产生副作用的命令

- 但可以做只读分析，例如阅读代码、搜索相关文件、梳理调用链、总结方案和风险

5. 如果你认为信息已经足够，请不要继续追问，而是明确告诉我：

- 你准备怎么做

- 为什么选这个方案

- 还有哪些风险或备选方案

然后等待我确认。

6. 如果某些细节不会实质影响结果，请自行做合理假设，并把假设写清楚，不要为了追求“100% 确定”而过度提问。

7. 请按任务大小调整流程：

- 如果任务很小、风险很低，请尽量简化流程，不要为了遵守格式而增加沟通成本

- 如果任务影响范围大、风险高、改动复杂，再提高澄清和确认的严格程度

```
