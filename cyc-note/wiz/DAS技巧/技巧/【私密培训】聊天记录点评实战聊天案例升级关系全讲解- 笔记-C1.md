# 总结

## 情感沟通核心理念讲解  06:37

看节奏而非内容

不管话题是否风趣幽默、有无态度、是否曲解画面，结果都一样，关键是节奏。

女生不讲逻辑

女生可能七点说不去蹦迪，十一点又去了，说明其行为不可预测。

高手思维

高手会通过节奏让女生对你上瘾，而不是靠内容或技术。

3. 聊天节奏解析  12:29

一句逗逼一句正经举例：

男生说“我到家太热了”，女生回“咋才到家？吹空调就不热了”，看似关心实为窗口。

正确回应：“要你吹”是带态度的指令式表达。

ps:总结的例子感觉有点问题

节奏决定关系走向

如果女生一直OO（冷淡回应），说明你的话题无效，问题不在技术而在节奏。

双线理论双线交叉：

一句逗逼一句正经，避免单一情绪输出，维持女生兴趣。

举例：先调情再正经，或先正经再调情，形成情绪反差。

什么是正确的节奏

一句逗逼(调情,表情包,曲解,开玩笑,呢 呀 嘻嘻等语气词)   一句正经  双线理论

(ps 一句话很容易不加语气词是正经 加了就变逗比) ps:也可以三句正经 三句逗比

一长一短 长短配合    (ps:也可以两句长 两句短  或两句短 两句长 )

聊天内容->  她 她 我 我 我们 然后循环 (ps:应该不是固定这样 而是说要从她到我到我们 她和我多一次少一次应该ok 我们后继续从头她开始)

错误的:

三句长 必死 无法升温

多次围绕对方+多次逗比 必死

-> 她 她 我们

ps:长->提供话题 提供话茬  短-> 应一下 (难怪 什么)
