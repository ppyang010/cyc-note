1. 用户在商城登录后会自动创建商城的业务用户

数据源：trade_account_user

其中：snsId 为商城用户的社区用户 ID

2. 在数据库中注册为管理员用户

数据源：trade_account_shop_user

其中：userId 为商城用户 ID，shopId 目前固定为 1

3. 在商城退出后，重新登录即可

4. 管理后台地址：http://mall.dxy.net/admin

Note:

> 核心代码：com.dxy.platform.plugin.sns.web.SignedCookieSessionManager.getSession(req, resp);

其中 snsSession.attr('s') 包含了商铺 ID 即拥有对应商铺的管理权限
