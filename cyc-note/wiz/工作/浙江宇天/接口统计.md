## 登陆页

#### 登陆接口

**请求方式 JSON**
POST /client/api/user/userLogin
**约束**
无
**请求消息体**

| **字段名** | **字段类型** | **出现次数** | **描述** |
| --- | --- | --- | --- |
| userName | String | 1 | 账号，号码/或邮箱 |
| password | String | 0..1 | 密码，通过MD5加密，选择密码登录时必填 |
| verifyCode | String | 0..1 | 验证码，选择验证码登录时必填 |
| loginMode | String | 0..1 | 登录方式(0:手机号密码登录，1：手机号验证码登录，2：邮箱，3：第三方账号，不传默认手机密码登录，其他方式必传) |
| identityid | String | 0..1 | 用户唯一标识(第三方账号登录必传) |
| tokenId | String | 0..1 | 第三方token(第三方账号登录必传) |

**响应消息体**

| **字段名** | **字段类型** | **出现次数** | **描述** |
| --- | --- | --- | --- |
| resultInfo | ResultInfo | 1 | 结果信息结构 |
| tokenId | String | 0..1 | 用户登录生成的唯一随机数，写入会话记录表、写入缓存（tokenId,会话信息实体） |
| firstLogin | boolean | 1 | True 首次登陆，已领取新手礼包，给用户相应的提示。<br>Flase 不是首次登陆。不需要提示 |
| userInfo | UserInformation | 0..1 | 用户信息，登陆成功后返回的用户信息 |
| versionInfo | ClientVersionInfo | 0..1 | 客户端升级版本信息<br>来源： [http://192.168.101.167:8090/pages/viewpage.action?pageId=1180104](http://192.168.101.167:8090/pages/viewpage.action?pageId=1180104) |
