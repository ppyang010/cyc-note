将文件上传到临时目录并将信息存入数据库 auditcontent_info表

{tmpFilePath}/yyyyMMdd/yyyyMMddhhmmss.zip  （SRCFILEPATH   ）

```
emanager.propertiestmpFilePath=/home/emanager/tempfiles
```

多线程任务 com.coder.video.emanager.content.task.VideoContentFTPReqTask

将文件转移到

{local-path}/MTN/VIDEO/{yyyyMMdd}/{contentId}/{yyyyMMddHHmmssSSS}.zip

（存入到数据库 auditcontent_info表 字段  LOCALFILEPATH = /MTN/VIDEO/{yyyyMMdd}/{contentId}/{yyyyMMddHHmmssSSS}.zip  （没有{locak-path}））

## TaskManager

```
/Video-Task/conf/taskManager/conf.properties相关配置文件videofile.sync.copy.vmsdir=/home/taskmanager/vms_dir/video_filevideofile.sync.manager.local.dir=/home/taskmanager# true:clean  false:not clean
videofile.sync.finlished.clean=false##======== video publish notify ======
videofile.publish.notify.url=http://192.168.200.147:8001/vmsServer/video/videoPubNotify
```

进行同步任务

com.coder.video.taskmger.task.queue.SyncVideoTaskScheduled.doWork()

进行同步操作的具体任务

com.coder.video.taskmger.service.impl.VideoManagerService.syncVideoToVMSFromLocal(String)

1.视频通过ftp上传至VMS平台

源地址   {videofile.sync.manager.local.dir}+LOCALFILEPATH

目标地址为 ~~{videofile.sync.copy.vmsdir}/home/videomanager/APPdir/tempfiles/{yyyyMMddHHmmssSSS}.zip~~

{videofile.sync.copy.vmsdir}/MTN/VIDEO/{yyyyMMdd}/{contentId}/{yyyyMMddHHmmssSSS}.zip

（这里实际是 {videofile.sync.copy.vmsdir}+LOCALFILEPATH  ）

2.将/MTN/VIDEO/{yyyyMMdd}/{contentId}/{yyyyMMddHHmmssSSS}.zip 写入 T_AUDITCONTENT_INFO表 <u>FILEPATH字段</u>

3.同步完成后是再将源文件清除（根据配置设置是否需要清除）{videofile.sync.finlished.clean}

4向VMS平台发送视频发布通知

通知地址{videofile.publish.notify.url}

参数

- contentID
- FilePath  =LOCALFILEPATH
- VideoName

T_AUDITCONTENT_INFO 内容表中的

CONTENTSTATUS

60,待分配 61,待初审 62,待终审 11,内容发布中 12,待上线 13,上线  16,已下线 77,驳回状态 89,否决状态  21基本信息录入， 22FTP下载异常，23待同步,24同步失败

SRCFILEPATH   视频Zip包对应的FTP文件路径或上传的临时文件路径，包含文件名

LOCALFILEPATH  视频Zip包在Manager本地保存的文件相对路径，包含文件名

FILEPATH   视频Zip包上传至VMS后的文件相对路径，包含文件名

SYNCSTATUS 内容同步中 0 未同步(0)，1 文件上传完成， 2 发布通知处理中， 3 发布成功，4 上传失败，5 发布通知处理失败
