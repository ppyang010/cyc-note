在目前国内的办公 Agent 里， **WorkBuddy** 确实跑得比较快。我们也陆续做过不少教程、测评和实战案例。

但内容多了以后，又有了一个新问题。

教程散落在不同的公众号里，新用户想系统学一遍，得自己到处翻。功能不少，真正打开 WorkBuddy 后，又不知道第一步该让它干什么。

这份蓝皮书并没有照着官方文档重新抄一遍。我们更想做的，是把各自真正跑过的任务、踩过的坑、做成的案例，整理成一份普通人也能直接照着用的 Agent 指南。

**蓝皮书的四部分内容**

**使用手册**

从安装、登录、第一个任务，到 Skill、连接器、API 和自动化。

**实战案例**

覆盖 Word、Excel、PPT、文件整理、会议、知识管理、投资、自媒体、AI 视频和 GEO 等场景。

**进阶方法**

怎么打造自己的 Skill，怎么设计多 Agent，怎么让自动化工作流跑得更稳。

**岗位与行业落地**

不同岗位、不同团队，如何把 WorkBuddy 真正用进工作里。

当然，这只是第一版。里面肯定还有遗漏，也可能有不准确、已经过时，甚至写错的地方。如果大家发现错误，欢迎随时拍砖，我们立刻改正~

**欢迎一起共创**

如果你在使用 WorkBuddy 时也跑通过真实任务，做过好用的 Skill，或者踩过值得提醒大家的坑，欢迎提交 Issue 或 Pull Request，一起参与共创。

一个人的教程，解决的是一个问题。

**大家一起补案例，才有可能把它变成一份真正好用的 WorkBuddy 工作地图。**
