别说Java，加上Scala我都没找出啥百分百满意的ORM，Slick太重，其它大多无法构造raw sql，而这是一些复杂业务的基础。

以前就职过一家公司，用jpa-jdbc，这是我心目中比较接近理想的ORM了，至少做常见应用是很方便的。

我自己还尝试写过一些便捷工具，但是要真正用起来方便，必须要做足功夫，工作量是必不可少的，没办法偷懒。
