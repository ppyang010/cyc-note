Spring 三级缓存，已经不是那么重要了；但是，你 9 年，jvm 应该要熟悉，什么字节码，双亲委派机制，这个学会，一劳永逸，绝对是性价比非常高的技能，也能解开你的一些疑惑（如果只学 java 语言），学会 jvm ，你学习 go 和 js，基本上没什么压力，因为 v8 和 go 的 gc ，和 java 本质上没什么不同；之后，就可以学习 docker + k8s 之类的，这是基操了（在 k8s 上跑 ci和 cd，以及日志系统，存储系统，监控和报警系统，这个技能绝对重要），顺便复习下 408 之类的（操作系统，数据结构和算法，计算机组成原理，计算机网络，有些知识过下即可，比如：hdd 不那么重要了），spi 就是 java的服务发现，和 目前的 nacos 等注册中心本质上没什么区别，只不过 spi 是 jdk 内置的，nacos 是抽取形成组件，springboot 的 starter 也是这样的原理。
