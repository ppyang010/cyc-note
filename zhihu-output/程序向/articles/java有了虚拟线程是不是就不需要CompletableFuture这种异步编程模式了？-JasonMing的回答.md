## 异步是异步，非阻塞是非阻塞。不要混为一谈。

异步是把一个任务分出去处理，并且当前流程中不再关心其后续结果的一种**逻辑结构/编程模型**。异步和具体执行逻辑的底层资源没有必定的联系，底层执行可以是线程也可以是协程。

非阻塞是某个任务在进入等待状态时不会妨碍执行这个任务的底层资源继续去执行其它任务。

虚拟线程的核心在于非阻塞，在虚拟线程上执行的任何 jdk 提供的等待函数都将不会**阻塞**实际的系统线程。

只不过当前重叠在了 Thread 这个概念上，让你们认为了这是个「异步」的工具。
