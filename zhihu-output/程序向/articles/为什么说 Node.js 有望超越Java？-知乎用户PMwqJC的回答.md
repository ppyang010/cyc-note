node对应的应该是java虚拟机，而不是java语言，硬要类比的话js或者ts才是对应java的语言。node的长处是在表现层，也可以说是人机交互的方面，但是这个方面从来不是java的长处，再做web应用的方面，能和java一战的简直不要太多。java的长处是对复杂业务的逻辑和海量数据的处理，在这个方面别说是node，就连别的语言我也没有看到短期内有能替代java的。

与其和java比，不如和PHP比更合适，毕竟这俩的定位都比较接近。“PHP是最好的语言”不知道被喊了多少年了，也该让位了，毕竟node不需要前端再多学一门编程语言了。java离了web容器还能使用socket通信，这就是java和脚本语言的本质区别。
