来吧！glibc 对 strlen 等函数的实现堪称暴力美学的典范，记住哟~ 最简单的需求往往隐藏着最惊人的力量！

要一个字节一字节地查找`'\0'`？不！太保守了，暴力起来！在现在的 64 位机器上，可以 8 个字 8 个字节地查找，也就是以`uint64_t`型变量为单位查找。

那么问题来了，如何判断 8 个字节中有`'\0'`呢？？

《[位运算的奇技淫巧](https://link.zhihu.com/?target=http%3A//graphics.stanford.edu/~seander/bithacks.html)》这部力作集位运算暴力美学之大成，其中介绍了一种高效方法：

[Determine if a word has a zero byte](https://link.zhihu.com/?target=https%3A//graphics.stanford.edu/~seander/bithacks.html%23ZeroInWord)

适用于 64 位字长的代码如下：

```cpp
bool has_zero_byte(uint64_t v)
{
    const uint64_t himagic = 0x8080808080808080;
    const uint64_t lomagic = 0x0101010101010101;

    return ((v - lomagic) & ~v & himagic) != 0;
}
```

对于 32 位字长，则可以是：

```cpp
bool has_zero_byte(uint32_t v)
{
    const uint32_t himagic = 0x80808080;
    const uint32_t lomagic = 0x01010101;

    return ((v - lomagic) & ~v & himagic) != 0;
}
```

原理是利用减法的借位，判断某个字节的比特位是否全是零：

1.  `(v - lomagic) & ~v` 判断是否有借位
2.  `(v - lomagic) & ~v & himagic` 判断是否有超出最高位的借位

`v`与`lomagic`相减，相当于将`v`中的每个字节与 1 相减，当一个字节不为零时，与 1 相减不会产生超出最高位的借位，否则会使所有比特位置 1；

相减后和 `~v` 按位与，可以将字节的低位置 1，而且是借了几位，就将低几位置 1，其他位为 0；

最后和`himagic`按位与正是判断是否产生了超出字节最高位的借位，如果结果不为 0 则说明存在某个字节为 0。
