这个skill存在的合理性就在于，它戳破了很多泡沫

包括但不限于：

```blitzmax
有了ai你就很厉害
有了ai你无所不能
这个功能一定有人喜欢
这个idea牛逼坏了
这个想法这么容易就能实现
......
```

ai大模型大概经历了这么个过程

| 阶段 | 关键词 | 本质 |
| ----- | ----- | ----- |
| 2022 | ChatGPT | AI 进入大众视野 |
| 2023 | GPT-4 | AI 具备知识工作能力 |
| 2023 | 工具调用 | AI 连接外部系统 |
| 2024 | 多模态 | AI 理解文字、图像、语音 |
| 2024 | 长上下文 | AI 处理大规模资料 |
| 2024—2025 | 开源追赶 | AI 能力扩散、成本下降 |
| 2024—2025 | 推理模型 | AI 开始“深度思考” |
| 2025—2026 | Agent | AI 开始执行复杂任务 |

这其中，最重要的部分其实是交互方式的进化

| 阶段 | 中文叫法 | 核心交互方式 | 本质 |
| ----- | ----- | ----- | ----- |
| 1 | Prompt Engineering | 写提示词 | 人通过语言控制模型 |
| 2 | Context Engineering | 喂资料、给背景、设记忆 | 人管理模型能看到什么 |
| 3 | Tool Use | 工具调用 | 模型开始连接外部系统 |
| 4 | Scaffold / Workflow | 脚手架 / 工作流 | 人用固定流程约束模型 |
| 5 | Agent | 智能体 | 模型自己规划、调用工具、推进任务 |
| 6 | Multi-Agent | 多 Agent 协作 | 多个角色分工协作 |
| 7 | Loop / Looper Agent | 闭环 Agent | AI 自己执行、评估、修正、迭代 |

所谓交互方式的进化就是，怎么让AI大模型了解更多地信息

分为这几个层级，我随手写的，大家理解个意思就行哈

**1、环境级memory——环境信息**

环境事实：设备、地理、用户不可变信息（id/tel/性别/民族等）

**2、用户级memory——长期记忆**

-   角色画像：人格、偏好、职业角色、语言习惯、行为特征
-   agent：用户偏好、任务历史、项目状态等

**3、项目级memory——中期记忆**

基于当前项目任务的全局记忆，项目背景、项目目标、项目周期、项目详情、项目进度等等

**4、会话级 memory——短期记忆**

context、会话分支、跨会话

  

当前各类 AI 工具都基于自身的工具特点做了一些调整，但逃脱不了上述范围。

可以这么说，当前Transformer架构的大模型训练收益远远小于在 memory 优化收益。

你可以这么理解，**发动机热效率受到自然法则限制向上突破越来越难，人们要的是汽车驾乘的整体体验**，这时候去提高发动机热效率的 ROI远远低于优化地盘、变速器、轮胎、座椅、智能化...等方面的 ROI。

对于生成式 AI 来说，在 memory 上的优化收益更大，包括但不限于记忆压缩、记忆调用、加载方式、检索方式等等。

基于这几种记忆来举个例子：

中国上海——Mac 设备——金融行业外企——投资分析师——严谨客观理性——以目标为导向——YouTube、抖音职业自媒体项目——选题/发布/数据分析/复盘

对应的 AI 大模型收到的是

自动任务的时区——设备环境——行业要求/规范——职业角色场景——语言风格——当前项目目标——当前阶段

如果把以上信息的完整度分为 5 颗星，每多1 颗星的体验提升都是跨级的。

通常初学者/新手都是在试探过程中逐步完善
