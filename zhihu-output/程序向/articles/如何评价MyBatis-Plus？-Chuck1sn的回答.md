**一个完成了他的历史使命，现如今已经过时了的框选。2025 年了就不要去学它了。**  

目前最流行的，在目前海外和国内最流行的现代 Java 技术框架有两个：

一个是 JOOQ、另外一个是 Jimmer；分别对应下面这个两个项目。

**Gitee**

**Github**

[(Github) 在海外爆火的吊打 Mybatis 的 DSL Query Library](https://link.zhihu.com/?target=https%3A//github.com/ccmjga/mjga-scaffold/)[(Github) 一个重新思考，重新设计，重新构建的现代 Java ORM](https://link.zhihu.com/?target=https%3A//github.com/ccmjga/mjga-scaffold/tree/model-first)

AI 时代的 2025 年，要用 Java，就要跟上时代的变化，而不能再去用老掉牙的那一套东西。这样才有助于提升我们的个人竞争力，不被时代所淘汰。

再说一下这个是脚手架的仓库。ORM 是脚手架使用的大量的库里面的其中一个。千万不要搞混了。对于新手来说，你可以直接去仓库里面看对应的 ORM 写出来的代码是什么样子的，比你去官网翻文档搞半天强一些。
