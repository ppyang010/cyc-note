做了一个挺小的东西：Tuleo，一个 AI 工具雷达。

起因很土：我每天在 X、Reddit、GitHub、知乎刷到各种 AI 工具，收藏夹越来越长，但真正试过的没几个。问题不是找不到工具，是不知道哪个值得花半小时打开。

所以我用 Vibe Coding 做了一个榜单站。它的流程大概是：先从 X / Reddit / GitHub / 知乎发现工具线索，再用知乎开放数据核实中文社区里有没有真实讨论，最后把讨论里反复出现的适用场景、优点、缺点整理出来。

现在能看的东西很简单：

-   首页：新收录、今日、最多讨论、上升最快、分类榜；
-   详情页：工具简介、适用场景、优缺点、相关来源；
-   提交入口：可以把新工具丢进线索池，但不会直接上榜。

开发过程基本是两天。代码主要交给 Codex，页面设计用了 Codex 的 Design 插件。我做的事更多是定边界：哪些数据算线索，什么情况下算“有讨论”，榜单不要变成广告位，详情页不要写成官网介绍。

做完之后最大的感受是，Vibe Coding 很适合把一个“我自己真的有这个问题”的小产品快速做出来。它不适合替你想明白产品，但很适合在你已经知道自己要解决什么时，把第一版推到可用状态。

Tuleo 现在还很早期，不是什么大项目。它更像我给自己做的一个 AI 工具筛选器：别再被“神器”“刚刚发布”“全网首发”这些词带着跑，先看看真实用户到底怎么讨论。
