现阶段，如果需要 coding agent，就用 acp 协议去调本地的 claude code cli 和 codex cli，很多产品都是这么做的，比如 multica、openclaw、zed 等等。这些就是业界最强的 coding agent，自己再费劲开发个效果又不好的完全没必要。。。

如果要快速搭建一个 agent，就直接用 pi，基于 pi-agent 来快速搭建 agent 出来，webui、tui 全都有。
