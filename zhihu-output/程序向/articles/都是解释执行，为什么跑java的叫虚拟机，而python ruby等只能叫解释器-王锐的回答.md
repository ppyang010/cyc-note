以前虚拟机和编译器，解释器的概念都是很清楚的，这些年大家都混着来很多时候概念都模糊了。

编译器是把源代码编译成机器可以执行的机器指令。

解释器是把源代码一行一行分析，直接执行源代码。

虚拟机是软件实现的虚拟处理器，有自己的指令。

随着发展，边界开始模糊。为了加速执行效率，出现了JIT编译器，就是把虚拟机指令或者解释器的源代码边执行，边编译到平台的真实指令。

  

Java和.NET都有自己的虚拟机，相当于有一个软件模拟的处理器，有自己的指令。在各个平台上只要实现这个软处理器，都可以执行Java和.NET的程序。所以说Java和.NET都是编译型语言，只是它们编译出来的是虚拟机的指令。

python和ruby说是解释语言也是早期它们刚刚出现的时候都是解释语言，要解释器执行。后来它们的JIT编译器方案也都很多，虚拟机方案也很多。但是大家说习惯了，就一直这样说下去了而已。
